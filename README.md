# Grupo Modalidad 40 - Landing Page de Alta Conversión

Sitio web oficial de captación y asesoría especializada en **Modalidad 40 IMSS (Ley 73)** para Grupo Modalidad 40. Diseñado bajo la estrategia **WhatsApp-First** y optimizado para máxima conversión, SEO semántico y tiempos de carga ultrarrápidos.

## 🚀 Características Principales

- **Embudo WhatsApp-First**:
  - 10 puntos de conversión estratégicos distribuidos en el recorrido del usuario.
  - Enlaces dinámicos con mensajes pre-llenados contextualmente.
  - Widget flotante con avatar y badge de mensaje pendiente.
  - Barra fija inferior (*Sticky Bottom Bar*) optimizada para dispositivos móviles (conversión con el pulgar).
- **Simulador Interactivo Ley 73**:
  - Cálculo paramétrico de semanas cotizadas y años de inversión.
  - Botón interactivo que transfiere el cálculo directamente al chat de WhatsApp con la asesora.
- **SEO & Rich Snippets**:
  - Metadatos OpenGraph y Twitter Cards.
  - Schema.org (JSON-LD) para `FinancialService` y `FAQPage` con soporte para resultados enriquecidos en Google.
- **Rendimiento & Accesibilidad**:
  - Vanilla HTML5, CSS3 y JavaScript moderno sin frameworks pesados.
  - Carga instantánea (< 1s) ideal para conexiones móviles.

